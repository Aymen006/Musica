## 🎧 What is Musica?

Musica is a **fully client-side** music player that runs directly in your browser.  
No installs. No servers. No accounts. Just music.

You can add your own songs, customize the player, and enjoy a clean listening experience.

---

## 🚀 How to Use

1. **Download** the project  
2. Open **index.html**  
3. Launch it in your **browser**  
4. 🎶 *Start listening!*

---

## ✨ Features

- 📥 Import & play your own music files  
- 🎨 Change cover art, song title & artist name  
- ⏯️ Play / Pause music  
- ⏭️ Next / Previous track  
- 🔁 Minimal UI designed for focus and simplicity  
- ⚡ Works on any device with a browser  

---

## 🛠️ Tech Stack

- **HTML**  
- **CSS**  
- **JavaScript**
